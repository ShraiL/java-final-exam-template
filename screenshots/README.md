# Required Screenshots

Save the final-exam screenshots in this folder before creating the submission ZIP.

Recommended files:

```text
01-javafx-form.png
02-product-inserted.png
03-pie-chart.png
04-phpmyadmin-table.png
```

## What Each Screenshot Should Show

### 01-javafx-form.png

The running JavaFX application with all form controls visible:

```text
Name
Category
Quantity
Price
Add Product button
PieChart
```

### 02-product-inserted.png

The JavaFX application after adding at least one valid product.

### 03-pie-chart.png

The PieChart with grouped totals visible, for example:

```text
Fish - 10
Bakery - 20
```

This can be the same screenshot as `02-product-inserted.png` if both the form and
updated chart are clearly visible.

### 04-phpmyadmin-table.png

phpMyAdmin showing:

```text
database: productdb
table: product
inserted rows
```

Open:

```text
productdb -> product -> Browse
```

## Screenshot Rules

- Show the relevant application, not the whole desktop when avoidable.
- Make database/table names readable.
- Make inserted values readable.
- Do not include passwords, private browser tabs, messages, or unrelated windows.
- Use PNG or JPG.
- Keep screenshots inside this folder before creating the ZIP.
